# 模拟题库

一个基于文档自动出题的本地题库工具：导入 PDF / DOCX / TXT → AI 生成题目 → 练习 → 错题本 → 统计分析 → 导出。

## 下载与源码

三个平台同步维护，源码内容完全一致，任选其一访问：

| 平台 | 下载最新版 | 源码仓库 | 说明 |
|---|---|---|---|
| **GitCode** | [Releases](https://gitcode.com/JinFengjian/moni-tiku/releases) | <https://gitcode.com/JinFengjian/moni-tiku> | 国内节点，下载与在线更新通常最快（推荐） |
| **GitHub** | [Releases](https://github.com/lingsheng24/moni-tiku/releases/latest) | <https://github.com/lingsheng24/moni-tiku> | 国际站点，国内访问可能较慢 |
| **Gitee** | — | <https://gitee.com/lingsheng24/moni-tiku> | 国内源码镜像（仅托管源码，安装包请从上两处下载） |

安装包分两种：`MoniTiKu-Setup-x.y.z.exe`（安装版，支持应用内在线更新）与 `模拟题库-x.y.z-portable.exe`（免安装便携版）。详见下方「桌面版 → 打包 exe」。

> 三平台的源码都是同一个仓库（`main` 分支）：GitCode / GitHub 同时承载安装包分发与自动更新，Gitee 仅作源码镜像与国内访问备份。

## 一、网页版（无需安装）

直接双击打开 `模拟题库-Web版.html`（Chrome / Edge 浏览器即可）。

- 数据保存在浏览器 IndexedDB 中，不上传服务器
- PDF / DOCX 解析库从 CDN 按需加载（需联网），TXT / MD 离线可用
- 首次使用请到「系统设置」填入 AI 接口信息

## 二、桌面版（推荐，功能更全）

### 运行

双击 `启动桌面版.cmd`（首次会自动安装依赖，约需几分钟）。

### 打包 exe

双击 `打包exe.cmd`，脚本会自动完成「打包 → 数字签名」，成品输出到 `发布\` 目录，包含两种：

- **安装版**（`MoniTiKu-Setup-x.y.z.exe`，NSIS）：双击安装，自选安装目录，自动创建桌面 / 开始菜单快捷方式，全中文安装向导，**支持应用内在线更新**
- **绿色便携版**（`模拟题库-x.y.z-portable.exe`）：免安装单文件，双击即用，**不支持在线更新**（需手动下载替换）

两者均带 Authenticode 数字签名（Valid + DigiCert 时间戳）。

> 安装版用英文名是为了 GitHub Release 分发（中文名会被 GitHub 破坏，见下方「发布到 GitHub」章节），不影响使用——安装后的快捷方式、卸载项、窗口标题全部是中文「模拟题库」。

### 应用图标

正式图标由 `desktop\生成图标.py` 程序化绘制（蓝紫渐变圆角底 + 翻开的书 + AI 星芒 + 对勾徽章），输出到 `desktop\icons\`：

- `icon.ico`：256 / 128 / 64 / 48 / 32 / 16 六档尺寸，打包时自动嵌入 exe 资源（文件资源管理器、任务栏、快捷方式均为正式图标）
- `icon_1024.png` / `icon_512.png`：发布宣传、商店用高清图

想改图标就编辑 `生成图标.py` 里的坐标参数重新运行，或把自制 `.ico` 覆盖 `icons\icon.ico` 后重新打包。

### 自动更新（安装版专属）

更新源已内置在软件里，**用户端无需任何配置**。每个版本同时发布到两个平台，互为备份：

| 平台 | 地址 | 特点 |
|---|---|---|
| GitCode | <https://gitcode.com/JinFengjian/moni-tiku> | 国内节点，实测 **6~8 MB/s**（90MB 约 15 秒），通常最快 |
| GitHub | <https://github.com/lingsheng24/moni-tiku> | 国内可能只有 0.06~0.4 MB/s，慢 |
| Gitee | <https://gitee.com/lingsheng24/moni-tiku> | 仅托管源码与镜像，**不参与自动更新**，也无安装包 |

软件每次「检查更新」会串行测速这 5 条线路（GitCode / GitHub / 3 个加速镜像），**自动选最快的**；用户也可在「系统设置 → 软件更新」手动锁定某条线路。

**发布新版（开发者）**

```
1. 在 CHANGELOG.md 最上方补写本版本的变更内容（类别：新增 / 优化 / 修复 / 变更 / 移除）
2. 改 desktop\package.json 的 version，双击 打包exe.cmd 打包并签名
3. 双击 一键发布.cmd，自动同时发布到 GitHub + GitCode
4. 双击 推送源码.cmd，把源码同步到 GitHub / GitCode / Gitee 三个仓库
```

> 第 4 步可省：Release 里已经有人能下载到新版，源码只是给想看代码的人。脚本会自动关掉证书吊销检查、清空代理（否则国内直连 GitHub 必失败），已推送过的会显示「已是最新」，重复运行无副作用。

Token 只需设置一次，存到本机用户环境变量后永久生效：

```bat
setx GH_TOKEN       <GitHub 个人访问令牌>     :: https://github.com/settings/tokens  勾选 repo
setx GITCODE_TOKEN  <GitCode 个人访问令牌>    :: gitcode.com → 设置 → 访问令牌  勾选 api
setx GITEE_TOKEN    <Gitee 个人访问令牌>      :: gitee.com → 设置 → 私人令牌  勾选 projects
```

> `GH_TOKEN` / `GITCODE_TOKEN` 供「一键发布」上传安装包；`GITEE_TOKEN` 仅在推送源码到 Gitee 镜像时用到（发布安装包不需要它）。

> 设置后**重新打开命令行窗口**才会生效。脚本读取顺序：进程环境变量 → 本机用户环境变量 → 命令行参数。

> 第 1 步别漏：脚本会自动读取 `CHANGELOG.md` 里当前版本的条目写进 Release 说明。
> 若忘了写，Release 里会显示一条「未填写」的占位提示，可随时补写后执行
> `node desktop\发布更新到GitHub.js --backfill` 回填（该命令只改说明、不传文件，
> 会按 CHANGELOG 里出现的版本号逐一更新已有 Release）。

脚本会自动完成「创建/复用仓库 → 创建 Release → 上传 4 个文件 → 写入变更说明」：

| 文件 | 作用 | 来源 |
|---|---|---|
| `latest.yml` | 版本清单（含版本号、SHA512、文件大小） | 签名后自动刷新 |
| `MoniTiKu-Setup-x.y.z.exe` | 安装包本体（**带数字签名**） | 签名后回写 |
| `MoniTiKu-Setup-x.y.z.exe.blockmap` | 差量更新索引 | 签名后重新生成 |
| `MoniTiKu-Portable-x.y.z.exe` | 绿色便携版（**带数字签名**），供手动下载 | 签名后回写 |

> ⚠️ **为什么上传的文件都是英文名**：GitHub 会对 Release 资源名里的非 ASCII 字符做 sanitize，中文名 `模拟题库-安装版-1.7.0.exe` 传上去会变成 `-.-1.7.0.exe`，导致更新下载 404。所以**上传到 GitHub 的一律用英文名**——安装版由 `package.json → build.nsis.artifactName` 控制，便携版由发布脚本自动重命名。**本地 `发布\` 目录里的便携版仍是中文名** `模拟题库-x.y.z-portable.exe`，方便自己分发。

> ⚠️ **签名必须在发布前完成，且要回写清单**：签名会改变文件内容。签名脚本会自动做三件事——把签名后的文件写回 `release\`（覆盖未签名原件）、重算 `latest.yml` 的 SHA512/size、用 `app-builder blockmap` 重新生成差量索引。**跳过任何一步，用户更新时都会因校验失败而装不上**。签名脚本支持重复运行（已签名的会跳过，不会叠加签名）。

Token 申请：<https://github.com/settings/tokens> → **Generate new token (classic)** → 勾选 `repo`。脚本只在你本机进程内使用，不会写入任何文件。

> ⚠️ **仓库必须是公开的**，否则用户端匿名下载不到更新包，会报更新失败。

**用户端更新流程**

点「检查更新」（或「帮助 → 检查更新」，启动后也会自动静默检查一次）：

| 步骤 | 行为 |
|---|---|
| ① 发现新版本 | 提示版本号，**询问是否下载**，你确认后才开始下载（带进度条，下载中可继续使用软件） |
| ② 下载完成 | 提示「更新已就绪」，**询问是否覆盖安装** |
| ③ 确认安装 | 程序退出 → **静默覆盖旧版**（无安装向导）→ 自动重新启动 |

两步都要本人确认，不会在后台偷偷下载或重启。

> **更换更新源**：所有候选下载源定义在 `desktop\main.js` 的 `UPDATE_SOURCES`（含 GitCode、GitHub 与 3 个加速镜像），改完重新打包即可，用户端界面上没有地址输入框。
>
> ⚠️ **GitCode 的附件直链只有一种写法**：`https://gitcode.com/<账号>/<仓库>/releases/download/latest/<文件名>`。官方文档示例里的 `-/releases/latest/downloads/` 和 GitHub 风格的 `releases/latest/download/` 返回的都是 **HTML 网页**（HTTP 200，但内容不是文件），拿它们当更新源会静默失败——已实测确认。
>
> **发新版**：只需把服务器上那三个文件替换成新的，用户端下次检查就会收到更新。
>
> 注意：绿色便携版不支持在线更新（electron-updater 限制），请下载新版替换文件。

### 数据文件位置（桌面版）

默认存于 `%APPDATA%\moni-tiku\data.json`。在「系统设置 → 数据管理」可以：

> 旧版本（1.7 之前）的数据在 `%APPDATA%\question-bank-generator\data.json`。升级到新版后首次启动会**自动把旧数据复制**到新目录，历史题目不会丢失；旧目录文件保留不动，可自行删除。

- **修改数据文件路径**：把整个 data.json 迁移到任意位置（如坚果云 / OneDrive 同步盘、移动硬盘），迁移时自动搬运现有数据并切换读写，多台电脑指向同一文件即可实现数据同步
- **恢复默认位置**：把自定义位置的数据搬回默认位置再切换，不丢数据
- 「数据」菜单 →「打开数据文件夹」可直接定位到当前数据文件

### 数字签名

项目自带自签名代码签名体系，`打包exe.cmd` 会自动调用签名脚本：

```
cert/
├─ rootCA.crt          自签名根证书（需加入「受信任的根证书颁发机构」）
├─ codesign.pfx        代码签名证书（含私钥，密码 Aa123456，可用环境变量 SIGN_PWD 覆盖）
desktop/
├─ 生成签名证书.js       按 openssl 重新生成一套证书（重置时使用）
└─ 签名exe.js          给 release 目录里最新的 exe 签名并输出到 发布/
```

签名使用 SHA256 摘要 + DigiCert 官方时间戳。时间戳的作用是：**即使证书日后过期，已签名的文件依然被视为有效**。

签名脚本会自动把证书导入当前用户证书区。若要在其他机器上看到「发布者已验证」，在那台机器上双击 `cert\rootCA.crt` → 「安装证书」→ 选择「当前用户」→ 「受信任的根证书颁发机构」即可。

> ⚠️ **自签名的局限**：它只让导入过根证书的机器信任你的程序，**不会**让 Windows SmartScreen 对公网用户放行。若要正式对外发布，请购买 OV（约 ¥1500/年）或 EV（约 ¥3000/年）代码签名证书，购买后把厂商给的 `.pfx` 覆盖 `cert\codesign.pfx`、删除 `cert\rootCA.crt`（改走公共 CA 链）即可，签名脚本无需改动。
>
> 如需卸载本机已安装的这套测试根证书：`certmgr.msc` → 受信任的根证书颁发机构 → 证书 → 找到 `JunGe Development Root CA` 右键删除。

### 桌面版相比网页版的优势

| 能力 | 网页版 | 桌面版 |
|---|---|---|
| PDF / DOCX 解析 | 依赖 CDN 联网 | 本地组件解析，离线可用 |
| AI 接口跨域限制 | 受浏览器 CORS 限制 | 主进程发请求，无跨域问题 |
| 数据存储 | 浏览器 IndexedDB | 本机 JSON 文件，可自定义存放位置（同步盘 / 移动硬盘），可直接备份 |
| 导出文件 | 浏览器下载目录 | 自定义保存位置（保存对话框） |
| 应用菜单 | — | 全中文菜单（文件 / 编辑 / 视图 / 数据 / 窗口 / 帮助） |

```

├─ main.js            主进程：本地存储 / 文件解析 / AI 代理 / 保存对话框 / 自动更新
├─ preload.js         安全桥接，暴露 window.electronAPI
├─ afterPack.js        打包钩子：用 rcedit 把图标与版本信息嵌入 exe
├─ package.json
├─ icons/             正式图标（icon.ico 多尺寸 + 高清 PNG）
├─ 生成图标.py         程序化绘制应用图标（需 Python + Pillow）
├─ 签名exe.js          给 release 目录全部 exe 签名并输出到 发布/
├─ 生成签名证书.js      生成自签名根 CA + 代码签名证书
├─ 启动桌面版.cmd      一键启动
├─ 打包exe.cmd        一键打包（安装版 + 便携版）并签名
├─ 一键发布.cmd        一键发布到 GitHub + GitCode（两个更新源）
├─ 一键发布.js         顺序调用下面两个脚本，任一失败不影响另一个
├─ 发布更新到GitHub.js  发布到 GitHub Release
├─ 发布更新到GitCode.js 发布到 GitCode Release（预签名地址 + PUT 两段式上传）
├─ 推送源码.cmd        一键把源码推到 GitHub / GitCode / Gitee（项目根目录）
└─ 推送源码.js         三平台 git push 封装（自动关吊销检查、清代理）
```

界面本身与网页版共用同一个 HTML 文件（`../模拟题库-Web版.html`），运行时会自动识别环境并切换数据/网络通道，因此两边功能保持一致。

## 四、主要功能

- **科目管理**：把文档归入不同科目（如语文 / 数学 / 法规），题目自动继承所属文档的科目。在「文档管理」页上方与「系统设置」页都能管理科目，两处实时联动；练习、组卷、题库、错题本、复习、图谱均支持按科目筛选，避免多科题目混在一起
- **文档管理**：文件导入或粘贴文本建文档，导入时可直接指定归入的科目，事后也能随时改
- **AI 生成题目**：单选 / 多选 / 判断 / 填空 / 简答 × 三档难度，自动避重，附答案、解析、知识点、原文出处
- **自定义题型**：在「AI 生成题目」页题型区点 **＋** 即可新增（选择式 / 文本式两种作答方式），点题型上的 **✕** 删除；与「系统设置 → 题目类型管理」双向同步，并自动接入出题、筛选、练习、考试分值、统计
- **知识点图谱**：按知识点聚合成 **3D 知识星球**（可拖动旋转、悬停高亮、点击详情、双击聚焦），有关系的知识点自动成簇；掌握度着色、薄弱知识点排序、一键专项练习、AI 批量补全标签
- **题库管理**：搜索、筛选、分页、在线编辑、批量删除、去重
- **答题练习**：题号导航、键盘快捷键、易错题优先、只练错题、AI 语义判分
- **模拟考试**：按条件组卷（科目 / 文档 / 知识点 / 题型 / 难度 / 题数 / 分值 / 时长），限时答题 + 答题卡 + 标记待定，交卷后统一批改（主观题 AI 判分或自评），生成成绩报告（分题型、分难度、逐题回顾），历史成绩与趋势图，可导出成绩单 HTML
- **组卷导出**：在模拟考试页按当前组卷条件直接生成可打印的试卷，支持 **Word(.docx)** 与 **PDF**，**A3（两栏·标准试卷版式）** 与 **A4** 两种纸张，**学生卷**（只有题目和作答空间）与 **教师卷**（带答案、解析、分值）两种卷种；试卷抬头含科目、考试名称、时长、满分与姓名/班级/学号栏，填空与简答题自动预留作答空行
- **间隔复习（SM-2 记忆曲线）**：把题目做成记忆卡片，按遗忘曲线自动排期；四档自评（忘记/困难/良好/简单）动态计算下次复习时间，忘记的卡片 10 分钟后重现；含今日队列、14 天到期预告、掌握阶段分布、每日新卡/复习上限、回忆式与作答式两种模式，练习与考试中的错题可自动入队
- **错题本**：自动收录、重练、答对自动移出、导出
- **统计分析**：正确率分布、近 7 天练习量
- **导出**：Word（.doc）、打印/导出 PDF（可含答案）、JSON 备份与恢复

## 五、模拟考试与组卷导出说明

1. 进入「模拟考试」，设定考试名称、组卷科目、选题范围、知识点、题型、难度、题数
2. 设置考试时长（可不计时）与各题型分值，页面会实时显示「匹配 N 题 · 满分 X 分」
2.5 **要用卷子**：直接在「组卷导出」面板选纸张（A4 单栏 / A3 两栏）、卷种（学生卷 / 教师卷）、格式（Word / PDF），点「生成并导出」即可；点「预览试卷」可先看排版。导出用的是与「开始考试」完全相同的一套组卷条件
3. 开始后进入答题界面：顶部倒计时（剩 5 分钟内变红，到点自动交卷）、下方答题卡（已答/未答/标记），支持 <kbd>A-D</kbd> / <kbd>1-4</kbd> 选择、<kbd>←</kbd><kbd>→</kbd> 翻页
4. 交卷后自动批改并写入：

   - 错失题目自动进「错题本」
   - 全部答题记录计入「统计分析」
   - 生成考试记录，可在「考试历史」查看报告、导出成绩单、查看成绩趋势

> 注意：考试期间不会显示答案与解析，避免边做边对；这与「答题练习」的即时判分模式互补。

## 六、间隔复习说明

1. **加入队列**：在「题库管理」点题目卡片上的「🔁 复习」，或在复习面板按文档/题型批量添加；错题本可一键全部加入。开启「练习答错自动入队」后，练习和考试中做错的题会自动进来。

2. **每日队列**：系统只把「到期的复习卡」+「受每日上限控制的新卡」放进今天的任务，避免一上来就几百张：
   - 今日待复习 = 到期且已学过的卡片
   - 今日可学新卡 = 从未学过的卡片，数量受「每日新卡上限」限制

3. **复习会话**：点「开始今日复习」进入卡片模式
   - <kbd>空格</kbd> 显示答案，<kbd>1</kbd> 忘记 / <kbd>2</kbd> 困难 / <kbd>3</kbd> 良好 / <kbd>4</kbd> 简单，<kbd>Esc</kbd> 退出
   - 每个按钮上会预览「多久后再来」，心里有数再点
   - 评「忘记」的卡片会在本轮末尾再次出现，短时强化

4. **调度算法（SM-2）**：

   | 评分 | 处理 | 下次间隔 |
   |---|---|---|
   | 忘记 | 轮次清零、熟悉因子 −0.2 | 10 分钟后 |
   | 困难 | 熟悉因子微调下调 | 上次间隔 × 因子 × 0.6 |
   | 良好 | 熟悉因子不变 | 第1次 1 天 → 第2次 3 天 → 之后 × 因子 |
   | 简单 | 熟悉因子 +0.1 | 第1次 4 天 → 第2次 8 天 → 之后 × 因子 × 1.3 |

   熟悉因子（ease）初始 2.5，下限 1.3、上限 2.8；间隔 ≥ 21 天的卡片标记为「已掌握」。

5. **到期预告**：复习面板的柱状图显示未来 14 天每天到期的卡片数，便于提前调剂，避免某天爆仓。

## 七、知识点图谱与题型管理

**图谱形态：3D 知识星球**

知识点均匀分布在球面上，**有关系的知识点会自动聚成一簇**（同一道题的多个知识点、常一起出现的知识点会靠在一起），一眼看出知识结构。

**操作**
- **拖动**：旋转球体（松手带惯性滑行）；空闲时会自动缓慢自转
- **滚轮**：缩放球体（50% ~ 320%）
- **悬停**：节点高亮并显示名称
- **单击**：选中该知识点，下方展开题目列表（同时球体自动把它转到正面）
- **双击**：聚焦到该知识点并放大
- 右上角按钮：<kbd>＋</kbd> 放大、<kbd>－</kbd> 缩小、<kbd>⟲</kbd> 重置视角、<kbd>⏸/▶</kbd> 暂停或开启自转、<kbd>⛶</kbd> 大图模式（高度放大到 72vh）
- 点击「薄弱 Top5 / 尚未练习 Top5」里的知识点，球体会自动转到它并展开详情

**实现说明**

纯 Canvas 2D 手绘的 3D 投影，零第三方依赖（不引入 Three.js / ECharts），单文件离线可用：
1. **球面布局**：斐波那契球（黄金角）均匀布点，再按图的邻接顺序 BFS 排序给出好起点
2. **球面松弛**：相连的用弹簧拉近、拥挤的用斥力推开，每步取切向分量移动并归一化回球面——索引相邻不等于空间相邻，这一步才是「成团」的关键（实测相连节点平均间距仅为任意两点间距的 0.22）
3. **投影**：绕 Y/X 轴旋转 + 透视除法，近大远小；节点按深度排序绘制形成遮挡，背面节点变淡且不画标签

**题型增删（两处入口，实时同步）**
- 「AI 生成题目」页题型区末尾的 <b>＋</b>：展开内联表单，填名称 + 选作答方式（选择式 / 文本式）即可添加，添加后自动选中
- 自定义题型右上角 <b>✕</b>：直接删除（会提示已有多少道该类型题目，删除后这些题保留可练）
- 「系统设置 → 题目类型管理」中同样可增删，两边数据实时一致；内置 5 种题型不可删除
