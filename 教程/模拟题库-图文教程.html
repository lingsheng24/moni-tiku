网页版（零安装体验）

不想装软件？直接双击项目里的 模拟题库-Web版.html（Chrome / Edge 打开），功能与桌面版基本一致，数据保存在浏览器里。差异是：PDF/DOCX 解析需联网加载组件、联网搜索受浏览器跨域限制只能在浏览器中打开搜索页。以下教程截图均来自与桌面版共用同一界面的 Web 版。

02三分钟上手

软件的核心工作流只有一条主线：

① 导入文档→② AI 生成题目→③ 答题练习→④ 错题重练 + 记忆曲线复习
  1. 导入文档：进入「文档管理」，把 PDF / DOCX / TXT / MD 学习资料导入（也可直接粘贴文本）。
  2. 配置 AI 接口（可选但强烈推荐）：到「系统设置 → AI 接口」填入 API Key。没有 Key 也能用「本地快速出题」，但 AI 出题质量与题型丰富度远胜本地模式。
  3. 生成题目：在「AI 生成题目」页选文档、题型、难度，点生成，题目自动带答案、解析、知识点和原文出处。
  4. 开始练习：进入「答题练习」抽题作答，客观题即时判分；做错的题自动进「错题本」，也可一键加入记忆曲线复习队列。
💡 提示所有数据都保存在本机（不上传服务器）。想多台电脑同步？在「系统设置 → 数据管理」把数据文件路径指到坚果云 / OneDrive 等同步盘目录即可。

03界面总览

启动后进入「首页总览」：文档数、题库题数、累计练习、错题数一目了然，还有今日复习提醒与总体正确率。

首页总览 · 顶部四张统计卡 + 今日复习提醒 + 快速开始入口

左侧导航栏从上到下依次是全部功能模块；底部「◀ 收起」可把导航折叠成纯图标模式，给正文腾地方。首页「快速开始」卡片就是第 02 节那条主线的快捷入口。

04文档管理与科目

文档是出题的素材来源。支持 PDF / DOCX / TXT / MD 四种格式，也可以直接粘贴文本。

文档管理 · 科目管理卡片 + 拖拽导入区 + 文档列表

导入文档

  1. 点击导入区选择文件（桌面版支持拖拽），弹窗中选择「归入科目」；
  2. 没有合适的科目？先在上方「科目管理」点「＋ 新建科目」，例如：计算机网络、数据库原理；
  3. 导入完成后列表会显示科目、大小、已出题数，随时可以点「出题」直接跳转生成页。

为什么要用科目

文档归入科目后，由它生成的题目自动继承科目。练习、考试、错题本、复习、图谱全都支持按科目筛选，多科资料混在一个题库里也不会互相干扰。科目在「文档管理」和「系统设置」两处都能管理，实时联动。

💡 提示删除文档不会删除已生成的题目；粘贴文本建文档时内容最好多于 30 字，太少会影响出题质量。

05AI 生成题目

内置 5 种题型（单选 / 多选 / 判断 / 填空 / 简答）× 三档难度，生成的每道题都附带答案、解析、知识点标签和原文出处。

AI 生成题目 · 选文档 → 勾题型难度 → 点「生成题目」

操作步骤

  1. 选择来源文档（或全部文档）；
  2. 勾选题型（默认单选 + 判断 + 填空），点题型区的 ＋ 可以自定义新题型，题型上的 ✕ 可删除自定义题型；
  3. 选择难度与每批题数，点「生成题目」；
  4. 生成完毕后点「去题库查看」直接检查成果。
⚠️ 注意AI 出题会自动避重——同一文档反复生成不会大量出重复题。生成期间请保持网络可用；API 费用按各服务商计费（每批 5 题通常不足 1 分钱，以 DeepSeek 为例）。

没有 API Key？

可以用「本地快速出题」：从文档中抽取关键句生成填空 / 判断题，完全离线免费，适合快速建库，但题型和质量不如 AI。API 配置方法见第 14 节。

06题库管理

所有生成题目的总仓库，支持搜索、组合筛选、在线编辑、批量删除与导出。

题库管理 · 顶部搜索 + 四维筛选，每题带标签、正确率与操作按钮
  • 搜索：输入关键词即时过滤题干 / 答案 / 解析 / 知识点；
  • 筛选：科目 × 文档 × 题型 × 难度四维组合；
  • 编辑：点「编辑」可改题干、选项、答案、解析与知识点；
  • 🔁 复习：把单题加入记忆曲线复习队列（见第 10 节）；
  • 导出：右上角「📤 导出 Word」「🖨 打印 / PDF」把筛选结果变成可打印材料。

07答题练习

从题库抽题作答，客观题即时判分，简答题 AI 语义判分。

练习设置 · 科目 / 范围 / 数量 / 题型 / 优先模式

「优先练习」三种模式：随机抽题（默认）、只练错题（配合错题本）、易错题优先（按历史错误率排序，错的多的题先来）。

答题界面 · 题号导航 + 进度条 + 单题作答
  • 顶部题号导航：答对的变绿、答错的变红，点击可来回跳题；
  • 键盘快捷键：A–D / 1–4 选择选项，Enter 提交，→ 下一题；
  • 提交后立即显示对错与解析；简答题由 AI 判断语义是否等价（未配 Key 时改为自评）；
  • 答错的题自动收入「错题本」；开启「练习答错自动入队」后还会自动加入复习队列。

08模拟考试与组卷导出

按条件组卷、限时答题、统一批改、生成成绩报告；还能把同一套组卷条件直接导出成可打印的 Word / PDF 试卷。

组卷并开始考试 · 名称 / 科目 / 知识点 / 题型 / 难度 / 题数 / 分值 / 时长，实时显示「匹配 N 题 · 满分 X 分」

考试流程

  1. 设定组卷条件与各题型分值，点「▶ 开始考试」；
  2. 顶部倒计时（最后 5 分钟变红，到点自动交卷），下方答题卡显示已答 / 未答 / 标记待定；
  3. 交卷后统一批改：客观题自动判分，简答题 AI 判分或自评；
  4. 错题自动进错题本，成绩写入历史并计入统计。
⚠️ 注意考试期间不显示答案与解析（和练习的即时判分模式互补），避免边做边对。
成绩报告 · 总分 / 用时 / 分题型·分难度得分 / 逐题回顾，可导出成绩单

「考试历史」里可以回看每份报告、查看成绩趋势图、导出成绩单 HTML。

组卷导出（Word / PDF 试卷）

组卷导出 · 用与「开始考试」完全相同的组卷条件直接出卷
选项可选拼合
纸张A4 单栏 / A3 两栏（标准试卷版式）
卷种学生卷（只有题目和作答空间）/ 教师卷（带答案、解析、分值）
格式Word 文档（.docx）/ PDF

试卷抬头自动包含科目、考试名称、时长、满分与姓名 / 班级 / 学号填写栏；填空与简答题自动预留作答空行。导出前可点「👁 预览试卷」先看排版。

09错题本

练习和考试中做错的题自动收录，支持重练、写笔记、一键全部加入复习队列。

错题本 · 每条错题记录你的错误答案、正确答案与错因
  • 重练答对后自动移出错题本（可在系统设置关闭）；
  • 可给错题写错题笔记，笔记会同步汇总到「知识库」（见第 13 节）；
  • 「全部加入复习」把所有错题塞进记忆曲线队列，考前冲刺利器。

10间隔复习（SM-2 记忆曲线）

把题目变成记忆卡片，按遗忘曲线自动排期，用最少的重复次数把知识刻进长期记忆。

间隔复习 · 今日队列 + 14 天到期预告 + 掌握阶段分布

怎么用

  1. 加卡：题库里点「🔁 复习」、错题本「全部加入」，或开启「练习答错自动入队」让错题自动进来；
  2. 每日队列：系统只把「到期卡 + 受每日上限控制的新卡」放进今天，避免一上来几百张；
  3. 复习：点「开始今日复习」进入卡片模式——空格 显示答案，然后按记忆情况自评：
评分快捷键效果
忘记1轮次清零，10 分钟后在本轮重现
困难2间隔微调缩短（上次间隔 × 因子 × 0.6）
良好3正常推进（1 天 → 3 天 → 之后按因子递增）
简单4加速推进（4 天 → 8 天 → 更长），Esc 退出

每个按钮上会预览「多久后再来」。间隔满 21 天的卡片自动标记为「已掌握」。柱状图显示未来 14 天每天到期的卡量，方便提前调剂、避免某天爆仓。

11统计分析

练习数据一览：正确率分布、近 7 天练习量，找出薄弱题型。

统计分析 · 累计练习 / 答对题数 / 总正确率 / 分题型·分难度正确率 / 近 7 天练习量

哪类题型正确率低就重点补哪类——回到练习页用「题型筛选 + 易错题优先」定向加练即可。

12知识点图谱

所有题目按知识点聚合成一颗可拖转的 3D「知识星球」，关系近的知识点自动聚成一簇，薄弱点一目了然。

知识点图谱 · 拖动旋转 / 滚轮缩放 / 悬停高亮 / 单击看题 / 双击聚焦
操作效果
拖动旋转球体（松手带惯性），空闲时自动缓慢自转
滚轮缩放（50% ~ 320%）
悬停节点高亮并显示名称
单击选中知识点，下方展开题目列表，球体自动把它转到正面
双击聚焦放大该知识点

节点颜色 = 掌握度（≥80% 绿 / 60–79% 橙 / <60% 红 / 灰 = 未练习）。下方「薄弱 Top5」「尚未练习 Top5」点击即可定位并一键专项练习；顶部还能勾选只看双链、同章节或「有笔记」的知识点。有笔记的节点带琥珀色光点，点击详情卡可直接查看 / 编辑笔记。

💡 提示知识点标签由 AI 出题时自动生成，也可以在题库编辑里手动修改；「AI 批量补全标签」可以给没有知识点的旧题批量打标。

13知识库与联网查询

四类内容统一沉淀：知识点笔记、错题笔记、自由手记、联网查询收藏。

知识库 · 分类统计 + 全文搜索 + 四类筛选，每条笔记可一键跳回对应页面
  • 📝 知识点笔记：在图谱详情卡里写，与图谱实时联动；
  • 📕 错题笔记：在错题本里给错题写备注；
  • 🗒 知识库手记：本页直接新建，可关联知识点；
  • ⭐ 查询收藏：联网查询时收藏的网页结果与 AI 问答，可「🔍 再查」「📝 转笔记」。

联网查询：不懂就搜，搜完就存

点知识库页的「🔍 联网查询」（或在图谱 / 练习里划选字词后点放大镜图标），弹出双栏面板：

联网查询 · 左栏网页结果（打开原文 / 复制链接 / 存笔记 / 收藏），右栏 AI 解答
  • 支持 4 个搜索引擎 + 智能聚合（三路并发、交替去重），被拦截时自动换引擎；
  • 输入时自动弹出搜索联想词（↑↓ 选择，回车搜索）；
  • 每条结果可「⭐ 收藏」进收藏夹（收藏夹就在知识库里）；
AI 解答 · 参考网页摘要讲解，可在下方输入框连续追问
  • 点「🤖 AI 解答」，AI 会结合左栏网页摘要用通俗的话讲清概念，避免瞎编；
  • 答完后在底部输入框继续追问，AI 记得前面聊过什么，多轮深挖；
  • 满意就点「💾 存进知识库」或「⭐ 收藏回答」，不想要直接关掉面板。
⚠️ 注意联网搜索需要桌面版 v1.36.0+（主进程抓取，不受浏览器跨域限制）；网页版会自动降级为打开浏览器搜索页，AI 解答不受影响。

15更新与常见问题

软件更新（安装版）

点左侧「系统设置 → 软件更新 → 检查更新」（启动时也会自动静默检查）。软件会串行测速 5 条下载线路并自动选最快的一条：

  1. 发现新版本 → 询问是否下载，确认后才开始（带进度条，下载中可继续使用软件）；
  2. 下载完成 → 询问是否安装；
  3. 确认后程序退出 → 静默覆盖旧版 → 自动重启，数据完好无损。
⚠️ 注意便携版不支持在线更新（技术限制），请到 Releases 下载新版替换文件。

常见问题

问题解决
AI 出题报错 / 超时检查 API Key 与 Base URL 是否填对、账户是否有余额；测试连通性后重试
PDF 导入失败（网页版）网页版解析库从 CDN 加载，需联网；桌面版本地解析无此问题
联网查询没有结果确认桌面版为 v1.36.0+；搜索引擎被拦截时软件会自动换引擎重试，也可手动切换引擎

想换电脑 / 多机同步「系统设置 → 数据管理」把数据路径指到同步盘目录，或直接拷贝 data.json
考试中途误关软件重新进入「模拟考试」可继续未完成的考试
